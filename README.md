# ⚽ Süper Lig Takip & Simülasyon Uygulaması (2026-2027)

Web Geliştirme dersi için React ve Tailwind CSS kullanarak hazırladığım lig takip ve CRUD projesi.

## 📌 Proje Hakkında
Bu projede 2026-2027 Trendyol Süper Lig sezonundaki 18 takımın puan durumu, maç sonuçları ve gol krallığı verilerini yönetebileceğiniz interaktif bir arayüz geliştirdim.

## 🚀 Neler Var?
- **Takım Yönetimi (CRUD):** Yeni takım ekleme, mevcut takımların puan/maç/averaj bilgilerini düzenleme ve silme.
- **Canlı Sıralama:** Girilen galibiyet, beraberlik, mağlubiyet ve averajlara göre otomatik puan hesaplama ve sıralama.
- **Maç Simülatörü:** İki takım seçip skor girerek veya rastgele skor üreterek lig tablosunu anında güncelleme.
- **Gol Krallığı:** Sezonun yıldız golcülerinin istatistikleri ve dinamik gol ekleme.
- **Mini Penaltı Oyunu:** Kaleciye karşı şut çekme ve atılan golleri takımın genel averajına yansıtma.
- **LocalStorage:** Sayfa yenilense bile veriler tarayıcıda saklanır.

## 🛠️ Kullanılan Teknolojiler
- React.js (Vite)
- Tailwind CSS
- LocalStorage API
- HTML5 / CSS3
